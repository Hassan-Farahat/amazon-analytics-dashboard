# Amazon Product & Pricing Intelligence Dashboard

A Python-based business intelligence dashboard tracking Amazon e-commerce metrics, pricing correlations, and brand performance.

## 🚀 Features
* **Interactive KPIs:** Tracks total products, average pricing, ratings, and discounts.
* **Dynamic Filtering:** Filter live data by product category and minimum rating.
* **Data Visualizations:** Scatter plots for price vs. rating correlation and bar charts for top brand performance.
* **Data Extraction:** One-click CSV download of filtered datasets.

## 🛠️ Tech Stack
* **Language:** Python
* **Framework:** Streamlit
* **Libraries:** Pandas (Data Cleaning), Plotly (Data Visualization)
